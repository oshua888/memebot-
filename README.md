# MemeBot — simulation

Scanner de meme coins + bot d'achat/vente **en argent fictif**, 3 stratégies comparées.
Tourne automatiquement toutes les ~5 minutes via GitHub Actions ; le tableau de bord
est publié sur GitHub Pages (dossier `docs/`).

Aucun achat réel, aucune clé de portefeuille. Les résultats passés ne prédisent rien.
